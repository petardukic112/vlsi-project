# VLSI/FPGA Project – DE0/DE0-CV

A VLSI/FPGA project targeting the **Intel/Altera DE0 and DE0-CV development boards**, developed using **Quartus II 13.1**. The project includes synthesizable Verilog HDL modules, simulation testbenches, FPGA configuration files, and generated synthesis and timing reports.

## Features

- DE0/DE0-CV top-level FPGA implementation
- Verilog HDL modules
- Separate simulation and synthesis source directories
- Quartus II project configuration
- Generated pin, fitter, assembler, and timing reports
- MIT license

## Repository Structure

```text
.
├── src/
│   ├── simulation/        # Simulation top modules and test modules
│   └── synthesis/         # Synthesizable Verilog source code
├── tooling/
│   ├── db/                # Quartus database files
│   ├── config/            # Project configuration
│   └── incremental_db/    # Incremental compilation data
├── db/                    # Additional Quartus database files
├── DE0_TOP.qsf            # Quartus project settings
├── DE0_TOP.qws            # Quartus workspace state
├── Projekat.qpf           # Quartus project file
└── LICENSE                # MIT license
```

## Requirements

- Intel/Altera **Quartus II 13.1** or a compatible version
- An Altera **DE0** or **DE0-CV** FPGA development board
- A supported FPGA programming cable
- A Verilog/SystemVerilog simulation tool, such as ModelSim

## Getting Started

### Open the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/petardukic112/vlsi-project.git
   cd vlsi-project
   ```

2. Open `Projekat.qpf` in Quartus II.

3. Verify that `src/synthesis/DE0_TOP.v` or `src/synthesis/DE0_CV_TOP.v` is selected as the appropriate top-level entity.

4. Compile the project using **Processing > Start Compilation**.

### Program the FPGA

1. Connect the DE0/DE0-CV board to your computer.
2. Open Quartus Programmer.
3. Load the generated `.sof` file from `tooling/DE0_TOP.sof`.
4. Select the correct FPGA device and start programming.

## Generated Results

The `tooling/` directory contains output generated by the Quartus toolchain, including:

| File | Description |
|---|---|
| `DE0_TOP.fit.summary` | Fitting summary |
| `DE0_TOP.fit.rpt` | Fitter report |
| `DE0_TOP.map.rpt` | Mapping report |
| `DE0_TOP.asm.rpt` | Assembler report |
| `DE0_TOP.sta.rpt` | Timing analysis report |
| `DE0_TOP.pin` | Generated pin assignments |
| `DE0_TOP.sof` | FPGA programming image |
| `DE0_TOP.eqn` | Generated equations |

## Development Notes

- `src/synthesis/` contains synthesizable RTL implementations.
- `src/simulation/` contains simulation sources and test modules.
- Files under `tooling/db/`, `tooling/incremental_db/`, and `db/` are primarily generated by Quartus and may vary between tool sessions.
- Quartus-generated reports should be interpreted using the corresponding Quartus software version.
